# Student Stress Prediction Using Smartphone Sensor Data

This project investigates the use of smartphone sensor data and machine learning techniques to predict stress levels in university students. The work focuses on preprocessing multimodal mobile sensing data and building reproducible machine learning pipelines for behavioral health analysis.

## Project Context

Stress monitoring in student populations is an important area of digital health research, as prolonged stress can negatively impact mental health, academic performance, and overall well-being. Smartphone-based sensing provides a non-invasive approach to capturing behavioral and contextual patterns associated with stress.

This project explores how mobile sensor data collected from iOS and Android devices can be processed and analyzed to identify trends and predict student stress states.

## Methods

* Data preprocessing and cleaning using Python and Jupyter Notebooks
* Separate preprocessing pipelines for iOS and Android sensor data
* Feature engineering from smartphone-derived behavioral signals
* Supervised machine learning workflows for stress prediction
* Comparative analysis of processed datasets across platforms
* Reproducible data preparation and modeling workflows

## Key Findings

The project demonstrates the potential of smartphone sensing data for identifying behavioral patterns associated with stress in students. Results highlighted the importance of preprocessing quality and platform-specific data handling when working with multimodal mobile health datasets.
